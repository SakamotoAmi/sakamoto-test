# Flower-Themed Puyo Puyo Game

## Game Description
The Flower-Themed Puyo Puyo game is a vibrant and engaging puzzle game where players match colorful flowers to clear the board. Each flower has its unique abilities, and the objective is to create combos for high scores.

## Difficulty Levels
- **Easy**: Slower falling speed, fewer flower types, and more time for decision-making.
- **Medium**: Standard speed, a moderate number of flower types, and balanced challenges.
- **Hard**: Faster falling speed, more flower types, and limit time for strategic moves.

## Controls
- **Left Arrow**: Move flower left
- **Right Arrow**: Move flower right
- **Down Arrow**: Drop flower quickly
- **Up Arrow**: Rotate flower
- **Spacebar**: Pause the game

## Score System
- **Single Match**: +100 points
- **Combo**: +50 points for each additional match
- **Clearing the board**: +1000 points bonus
